Snoise Editor

Remove steady background noise (fan, hiss, hum) from a recording.

Quick start

  1. Open a recording with File > Open Audio (⌘O), or drop an audio file on the window. WAV, AIFF, FLAC and MP3 are supported.
  2. Show the app what the noise sounds like. Drag across a part of the waveform that contains only noise (no speech or music), or load a separate noise-only recording with File > Open Noise File (⌘⇧O) or by dropping it on the Noise profile card. A noise-only file must have the same sample rate as the recording.
  3. Process. Press Process or ⌘↩. The button shows progress and turns into Cancel while it runs.
  4. Compare. Switch between Original and Processed with the toggle, 1 / 2, or Tab. Playback keeps its position when you switch.
  5. Export. File > Export Processed Audio (⌘E) saves a WAV. If the audio would clip, you are offered a normalised copy.

Noise reduction (alpha)

The knob sets alpha: how much of the noise estimate is subtracted. Higher values remove more noise but can leave "musical noise" (bubbling tones) and make speech sound thin. The default is 1.0. Change it with the knob, by typing in the value box, or with the keyboard (] / [ in steps of 0.1, add Shift for 0.01, \ to reset).

After you change alpha or the noise region, the processed audio is out of date. Export is disabled until you press Process again, so an exported file always matches the alpha on screen.

Zooming and scrolling

  • Hold ⌘ and scroll, or pinch on a trackpad, to zoom around the pointer. The waveform and both spectrograms zoom together.
  • Scroll or swipe sideways to move through time; the bar under the waveform also scrolls.
  • ⌘= / ⌘- zoom in and out, ⌘0 fits the whole file, Z zooms to the marked noise region.

Choosing an audio device

By default Snoise Editor plays through the system output. To use another device, such as an audio interface, open Options > Audio Settings... and pick it from the output list. You can also change the sample rate and buffer size there. The choice is remembered between launches; if that device is not connected next time, the app falls back to the system default.

Drag and drop

Dropping a file on the waveform or spectrograms opens it as the recording. Dropping on the Noise profile card loads it as the noise file (or as the recording, if none is open yet). Files are ignored while processing.

Keyboard shortcuts

On macOS ⌘ is Cmd; on Windows and Linux it is Ctrl. Every shortcut can be changed in Help > Keyboard Shortcuts (⌘,); changes are kept between launches.

Tips

  • Choose a noise region that is at least a second long and contains only the noise you want to remove. The profile plot should look smooth.
  • Start at alpha 1.0 and raise it only if noise remains. Listen for thin or "watery" sounds as a sign it is too high.
  • This works best on steady noise. It cannot follow noise that changes over time.
  • If Snoise Editor cannot open an audio device, processing and exporting still work; only playback is unavailable. Try another device in Options > Audio Settings....

If something goes wrong

  • "Noise section is too short": mark a longer region (at least one analysis frame, about 46 ms; a second or more is better).
  • Sample-rate mismatch: the noise file and the recording must have the same sample rate.
  • Reset to defaults: delete ~/Library/Application Support/SpectralNoiseCancellation/SpectralNoiseCancellation.settings while the app is closed.
